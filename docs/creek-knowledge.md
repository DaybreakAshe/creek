# Creek 产品知识库

供 Creek 站内 AI 聊天助手（`/api/chat`）作为 RAG 上下文使用。更新产品说明时请编辑本文件。

## 网站定位

Creek（https://www.icreek.xyz）是一个面向创作者与设计爱好者的个人站点，Slogan：**源于自然，为你精选**。

核心能力：

1. **作品瀑布流（首页）** — 浏览全站公开的图片/视频作品；登录后可上传并管理自己的作品。
2. **工具集合** — 收藏与分享常用在线工具链接（名称、网址、描述、分类、图标），支持公开或仅自己可见。
3. **AI 聊天** — 登录后使用，基于 Google Gemini，流式回复、支持 Markdown；可解答 Creek 使用问题、工具推荐、创作灵感等。
4. **账户与多语言** — Google 一键登录；中英文界面；亮色/暗色/跟随系统主题。

## 主要页面与路径

| 路径 | 说明 | 是否需要登录 |

| `/` | 首页：公开作品瀑布流、上传作品入口 | 上传需登录 |

## 作品（Gallery）使用说明

- **上传入口**：首页右上角「添加作品」。
- **媒体类型**：图片、视频（本地文件或外部 https 链接）。
- **本地文件**：上传至 **Sirv CDN** 存储。
- **可填信息**：标题、描述、标签、无障碍说明、是否公开展示。
- **管理**：登录后访问「我的作品」(`/gallery/mine`) 可搜索、预览、删除。
- **首页展示**：仅**公开**作品出现在首页瀑布流。

## 工具（Tools）使用说明

- **浏览**：`/tools` 查看所有用户设为公开的工具。
- **管理**：`/tools/mine` 添加工具，填写名称、网址、描述、分类（默认 `general`）、可选图标；可勾选「公开」。
- **图标**：可上传 JPG/PNG，不上传则显示默认图标。
- **删除**：在「我的工具」中可编辑、删除（不可恢复）。

## AI 聊天使用说明

- **入口**：导航栏「聊天」→ `/chat`。
- **登录**：须先用 Google 登录；未登录访问会引导至 `/chat/new` 登录页。
- **模型**：Gemini（默认 `gemini-2.5-flash`）。
- **对话管理**：左侧历史列表；「新对话」创建会话；可删除历史对话。
- **对话 ID**：每条对话有 UUID，URL 形如 `/chat/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`。
- **存储位置**：对话记录保存在**当前浏览器 localStorage**（按用户 ID 隔离），**不会同步到服务器**；分享链接仅在同一浏览器、同一登录账号下能打开对应对话；换设备或他人打开链接看不到你的历史。
- **能力边界**：可介绍 Creek 功能、推荐工具、创作建议；无法代替用户在网站上代为上传作品或修改数据库。

## 登录与账户

- **方式**：Google OAuth（NextAuth）。
- **个人主页** `/profile`：可查看 **User ID**（用于配置管理员）。
- **退出**：用户菜单 → 退出登录。

## 管理员

- 将管理员的 User ID 写入环境变量 `ADMIN_USER_ID` 后，该账号可访问 `/admin`。
- 管理员可：管理全站工具、查看注册用户、管理全站作品。

## 常见问题（FAQ）

**Q：如何上传第一张作品？**  
A：Google 登录 → 首页「添加作品」→ 选择图片或视频（或填写外链）→ 填写标题等信息 → 保存。

**Q：工具「公开」和「私有」有什么区别？**  
A：公开工具会出现在 `/tools` 所有人可见；私有仅在自己「我的工具」中可见。

**Q：AI 聊天数据存在哪里？**  
A：存在本机浏览器 localStorage，未上云；清除站点数据会丢失历史。

**Q：网站支持哪些语言？**  
A：中文（默认）、英文；页头可切换语言。
